Files archived or derived from https://github.com/daeken/ReCurta

Per the upstream project, they translated the original Curta Type I engineering
diagrams into English, redrew them using CAD software (Solidworks, apparently),
and uploaded both drawings and prt files.  The original project does not, as
far as I can tell, have an assembly of the full Curta in 3D space.

This project is of particular note because (unlike most other Curta models I am
aware of) the project explicitly states:

   Everything produced as part of this project is being released into the
   public domain.

Rather than a full mirror of all ReCurta archive contents, we will store just
the key data and CAD files here.  We'll archive the original Solidworks files
for completeness, but for the drawings we will highlight the PDFs and the parts
we will store as STEP files (converted through OnShape.)
