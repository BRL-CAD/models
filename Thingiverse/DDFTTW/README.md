This is the STEP files for a model by XylaF for a model vehicle that can drive
directly downwind faster than the wind (usually tested by putting the car on a
treadmill and having it climb the treadmill - equivalent experiment from a
frames-of-reference physics standpoint.)

If you search online you will find quite a lot about this idea and the full
sized version that was created to prove the concept in real life at scale.
